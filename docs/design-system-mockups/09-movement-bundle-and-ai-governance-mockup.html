  • 기기 내 규칙 모드: 외부 네트워크 전송 없이 로컬 코드(freeAiClient.ts)만으로 동작
  • 서버 무료 모델 가드: 백엔드(freeAiService.ts)에서 :free(max_price=0) 또는 무료 티어 확인 환경변수가 없으면 호출 차단

  • 외부 구독·IDE 크레딧 호환: 개인 구독·IDE 크레딧·API 선불 잔액은 정산 체계가 달라 동일 크레딧으로 간주할 수 없음
  • 서버 실행 상태: 로컬·호스팅 백엔드 미실행 시 서버 AI 모드는 연결 오류가 발생하며 규칙 모드만 사용 가능
