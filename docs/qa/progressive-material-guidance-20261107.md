# 수업 구성의 반복 관리 안내 정리

동작을 고르고 순서를 구성하는 화면에서 검토 기록 관리 설명이 반복되던 부분을 정리했다.

- 동작 찾기 상단은 ‘동작을 골라 수업에 추가하세요’로 짧게 안내한다.
- 수업 하단은 시간/준비 요약을 유지하고, 미검토 개수와 검토 기록 설명을 기본 접힘 ‘자료 안내’에 둔다.
- 전역 검토 안내의 ‘동작 자료·기록 보기’ 탐색 버튼은 안내를 펼쳤을 때 보인다. 기존 동작 라이브러리로 이동하는 기능은 유지한다.
- 개별 동작의 ‘검토 전 자료’, 모션/해부학의 미검증 경고, 원본/출처, 기존 사용자 검토 기록은 바꾸지 않는다. 추가·편집·저장에 검토 gate를 만들지 않는다.
- 기록 유무가 실제 동작 정확성/개인별 운동 적합성을 보장한다는 오해를 방지한다. 이 변경은 전문 동작 검증이나 안전성 판정이 아니다.

회귀에서는 기본 접힘, 키보드 Enter 열기/닫기, 동작별 상태 가시성, 저장 데이터/검토 상태 불변을 확인한다. 수업 구성의 모바일·태블릿·PC 실제 검증 및 전체 검사 결과는 실행 결과로 따로 확인한다. 전체 화면 시안 구현 완료를 뜻하지 않는다.
