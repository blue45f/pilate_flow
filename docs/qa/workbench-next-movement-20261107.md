# 다음 동작 추가 동선

첫 동작을 추가한 뒤 핵심 버튼의 '+' 아이콘만으로 다음 행동을 유추해야 했다. 기존 동작 추가 기능을 그대로 유지하고 '동작 추가'를 눈에 보이는 글자로 표시했다.600px 이하에서는 추가/보조 버튼을 한 줄, 미리보기를 다음 줄로 배치해 좁은 화면에서도 의미와 터치 영역을 유지한다. 기존 시안의 색·모서리·여백을 유지하며 기능·데이터·검토 조건을 변경하지 않았다.

검증:

- 전체190파일/2096테스트 통과. 추가 테스트의 Testing Library 옵션 타입 오류를 제거하고 해당11테스트 및 타입·린트·빌드·PWA·ledger 재검증 통과.
- 개발/빌드 Chrome320/390/600/768/1440px: 보이는 글자,44px 이상 조작 영역, 버튼 겹침 없음, 첫 동작→추가 버튼 키보드 실행→두 번째 동작→저장→재접속 일치.
- 기존7폭 picker 회귀: 선택·필터·초점·정렬·되돌리기·저장·숨은 재생 중지 통과.
- 390px 스크린샷 육안 확인. Safari/실기 검증은 별도 미수행.
- 다른 worktree 및 사용자 데이터 미수정. Gemini 새 요청·운영 배포 없음.
