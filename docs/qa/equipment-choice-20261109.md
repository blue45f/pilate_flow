# 기구 선택 그림·설명 개선

## 범위

- 기구 8종과 소도구 13종에 직접 제작한 SVG 도해와 짧은 형태·용도 설명을 추가했습니다.
- 설정의 보유 장비, 라이브러리의 보유 장비 편집, 장소 관리, 수업 조건에서 같은 카드를 사용합니다.
- 매트, 미니볼/짐볼, 써클링/루프 밴드, 튜브/롱 밴드, 캐딜락/타워, 바렐 종류를 서로 구별합니다.
- 종류 미지정 바렐·탄력 밴드는 구체적인 종류를 확인하도록 설명합니다. 도해는 제품 사진이나 운동 처방이 아닙니다.
- 기존 카탈로그 ID, 보유 상태, 장소 저장 동작, 기구 사용 가능 조건은 변경하지 않습니다. 보유 장비 검색 범위 동기화 변경과 함께 통합 검증했습니다.

## 접근성과 모바일

- 설정·장소·수업 조건은 네이티브 체크박스를 유지하고, 라이브러리 보유 편집은 기존 버튼/aria-pressed 방식을 유지합니다.
- 기존 한국어 이름은 aria-labelledby, 용도는 aria-describedby로 분리해 이름으로 컨트롤을 찾는 동작을 유지합니다.
- 그림은 중복 낭독을 피하도록 장식 처리합니다. 모든 도해에는 같은 텍스트 설명이 함께 표시됩니다.
- 카드 전체를 누를 수 있으며 선택 체크 표시, 키보드 포커스, 미보유 비활성 표시를 유지합니다.
- 좁은 컨테이너에서 한 열, 넓은 컨테이너에서는 가용 폭에 맞춰 여러 열을 사용합니다. 이미지 다운로드나 애니메이션은 없습니다.

## 확인한 결과

- 신규 단위 테스트 6개: 전체 21종 도해·설명, 고유 그림, 접근성 이름·설명, 버튼/체크박스, 비활성, 다중 선택·전체 해제, 중복 ID 방지.
- 관련 UI 테스트 15개 통과.
- TypeScript 검사, 프로덕션 빌드 및 PWA 정적 파일 검증 통과. 기존 큰 청크 경고는 남습니다.
- Chromium 실제 화면 320/390/768/1440px 통과. 각 폭에서 21개 카드, 체크박스/버튼 Space 조작, 독립 다중 선택, 빈 보유 목록, 재로드 유지, 라이브러리 보유 편집 연동, 장소 저장/취소, 미보유 기구 비활성 및 가로 넘침 없음 확인.
- 최종 통합 전체 테스트: 261개 파일, 2747개 테스트 모두 통과. 기구 카드 및 보유 범위 동기화를 함께 검사했습니다.
- 기존 PWA 저장 무결성 테스트의 합성 데이터에 새 영속 설정 exerciseBrowseScope가 누락된 것을 수정했습니다. 비기본값 all이 계정 동기화와 오프라인 재방문 후에도 유지되는 검사를 추가하고, 원래의 전체 바이트·SHA-256 비교는 그대로 유지했습니다.
- 전체 ESLint 오류 0개(기존 react-refresh 경고 1개), 비밀정보 검사와 모션 원장 검사 통과. 최종 TypeScript 및 PWA fixture 린트도 통과했습니다.
- 통합 화면에서 장비 범위 UI, 빈 보유 목록에서 전체 보기 복귀, 재로드 범위 보존, 라이브러리와 작업대 동작 찾기 연동을 320/390/1440px에서 추가 확인했습니다.
- Safari/실제 모바일 기기 및 실제 스크린리더 낭독은 이번 검사에 포함하지 않았습니다.

## 재현

정상 설치된 환경에서 pnpm test, pnpm lint, pnpm build, pnpm check:secrets, pnpm check:motion-study를 실행합니다.

브라우저 검사는 기존 설치한 Playwright 모듈, 별도 Chromium 프로필, 로컬 Vite 서버를 사용합니다.

    PLAYWRIGHT_MODULE=/path/to/playwright BASE_URL=http://127.0.0.1:5247 OUT_DIR=/path/to/qa-output node scripts/qa/equipment-choice-browser.cjs

스크린샷과 results.json은 지정한 출력 폴더에만 기록합니다. 테스트는 합성 장소 이름과 새 로컬 브라우저 상태를 사용하며 운영 데이터 또는 로그인된 브라우저를 사용하지 않습니다.
