# 패턴 버튼 가독성 및 터치 영역

동작 라이브러리 패턴 버튼의 line-height:1.7이 뒤의 font:inherit에 덮이는 CSS 결함을 수정했다. 기존 색·형태·레이아웃을 유지하며 모든 화면의 최소 터치 높이를44px로 일치시켰다. 데이터·동작 정확성·재생 기능에는 변경이 없다.

- 전체190파일/2095테스트, 타입·린트·빌드·PWA 검증 통과.
- Chrome 개발 및 빌드320/390/768/1440px에서 실제 computed line-height/font-size 비율1.7, 높이44px, 키보드 Enter로 패턴 열기, localStorage 불변 및 수평 넘침 없음 확인.
- 390px 스크린샷 육안 확인. 별도 임시 브라우저만 사용했다. Safari 및 실기 테스트는 수행하지 않았다.
- 첫 브라우저 선택자는 메뉴의 접근성 이름 공백을 고려하지 않아 실패했고, 이름의 고정 숫자 제거 후 재검증 통과했다.
- 원격 base5896bf2. 운영 HTML/SW 지문은 기존29a6edb/f963706과 동일하며 배포하지 않았다.
