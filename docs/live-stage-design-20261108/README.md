# 수업 진행 화면 시안 기반 구현

기준 원격 main: 61bffde20c2af7a70fb0733807f69228eac7df10. 독립 브랜치 feat/live-stage-design-20261108.

실제로 열어 대조한 시안은 `live-stage-three-devices-concept.png`이다. SHA256: 48e6a4d227f794b8d2963d142181b5d35ceafa4023038f12a8a622dd5ab404d3. 시안의 사용자 승인 여부를 이 보고서에서 단정하지 않는다.

## 구현 범위
- 현재 동작, 타이머, 이전/시작/다음 순서로 정보 우선을 정리했다. 숫자를 상태 표시 위로 옮기고 민트색 구간 머리글을 반영했다.
- 시간 상세, 음성 세부설정, 티칭 큐/메모, 기구 세팅/주의사항을 펼침형으로 정리했다. 모든 원문 내용은 유지했다.
- 음성 켜기/끄기와 즉시 중지 버튼은 항상 노출한다. 음성은 계속 수업별 opt-in이다.
- 오늘의 흐름은 PC에서 오른쪽 열로 옮겼다. 처음 진입하는 모바일/태블릿에서는 접힘 상태이며 직접 펼칠 수 있다. 화면을 회전해도 현재 접힘 상태를 강제로 초기화하지 않는다.
- 320px 상단 조작 충돌을 해소하고 이전/다음 글자가 낱글자로 줄바뀌지 않도록 조정했다.
- 타이머 계산, 수업 기록/로그, 음성 엔진, 도해, 저장 데이터 로직, 공유 CSS는 변경하지 않았다.

## 증거와 한계
before/after 이미지는 변경 전과 중간 결과, final-WIDTH-HEIGHT.png는 최종 실브라우저 화면이다. 모두 실제 운동 지시가 아닌 합성 QA 동작을 사용했다. 원본 시안과 스크린샷을 혼동하지 말 것.

격리 Chrome에서 320×900, 390×900, 768×1024, 1440×900, 390×500을 검증한다. 가로 넘침, 접힘/펼침, 음성 초기 꺼짐, 타이머 시작/일시정지, 1분 추가, 다음/이전, 고대비, 종료 검토 후 계획 복귀를 확인한다. 실제 기기/OS 키보드/Safari/음성 발화의 청취 검증은 포함하지 않는다. 음성 회귀는 기존 모의 기기 음성 테스트로 별도 확인한다. 운영 배포는 하지 않는다.

## 재현
앱 개발 서버를 localhost5273에 실행한 뒤 PLAYWRIGHT_PATH를 설치된 Playwright 모듈 경로로 설정하고 `node docs/live-stage-design-20261108/verify.cjs final`을 실행한다. 사용자 브라우저 프로필을 사용하지 않는다.
