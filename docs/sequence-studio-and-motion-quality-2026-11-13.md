# 시퀀스 작성 재구성과 모션 품질 개선

작성일: 2026-11-13. 기준 main: `f3641ef9293e51cb2358dfd387a04fb13a0a5cc6`.

## 변경 배경과 동시 작업 처리

기존 98종 카탈로그와 24개 3D 이미지 패밀리는 서로 일대일 관계가 아니다. 파일 존재 검사는 인체·기구·연결 자세의 정확성을 보장하지 않으며, 이름 규칙으로 찾은 패밀리 그림을 해당 동작의 검증된 영상처럼 표시해서도 안 된다. 기존 3D PNG의 파일명을 유지하는 것과 실제 사용자가 보는 그림을 개선하는 것은 구분했다.

작업 시작 시 원격 main과 기존 작업 디렉터리의 미커밋 변경을 대조했다. 기존 디렉터리는 건드리지 않고 main 기준 별도 worktree에 필요한 모션·자료 개선을 선별 통합했다. 저장소에 보이는 작업만 확인했으며, Gemini 웹 세션의 실행 내용이나 작성자를 확인한 것으로 간주하지 않았다. 이번 변경이 수업 작성·저장·일정·복구에 이미 반영된 기능을 덮어쓰지 않도록 기존 store, 타이머, 가져오기, 복구 핸들러를 재사용했다.

## 새 기본 작업 흐름

1. **수업 조건**: 수업 이름, 기구, 최대 난이도, 목표 시간. 세부 기구와 소도구는 조건 창에서 선택한다.
2. **동작 찾기**: 현재 수업 기구의 동작을 검색하고 준비/코어/하체/상체/마무리로 좁힌다. 그림과 이름은 같은 상세 화면을 연다. 추가 성공 여부는 store의 반환 결과로 표시한다.
3. **내 시퀀스**: 실제 순서를 그대로 보여주며 드래그 또는 위·아래 버튼으로 이동한다. 잠긴 행의 내용과 위치는 보호한다. 삭제는 되돌릴 수 있다.
4. **시간과 메모**: 해당 행을 열어 전체 시간, 설명, 전환, 횟수, 좌우, 수업 구간과 메모를 한 번에 바꾼다. 양쪽 수행과 설명·전환은 전체 시간에 포함된다. 영상 길이나 모션 프리뷰 주기로 운동 시간을 추정하지 않는다.
5. **저장과 진행**: 항상 보이는 합계와 저장/시작 버튼을 사용한다. 목표 시간 차이는 안내하며 유효한 수업의 시작을 임의로 차단하지 않는다. 저장 오류가 나면 저장하고 새로 만들기를 완료한 것으로 표시하지 않는다.

데스크톱에서는 동작 목록과 수업안을 나란히 놓는다. 작은 화면에서는 `내 시퀀스 / 동작 찾기`로 전환한다. 템플릿, 영상 가져오기, 사용자 동작, 자동 구성 및 기존 정밀 편집 기능은 보조 진입으로 유지한다. 진행 화면을 떠날 때 기존 타이머 이탈 보호를 우회하지 않는다.

유효한 제목·목표 시간은 입력 중에도 보관한다. 기존 휴식보다 짧은 목표처럼 수업 검증에서 거부된 입력은 오류로 표시하고, 편집을 마치면 실제 적용값으로 복원한다. 고급 편집의 미적용 생성 조건은 현재 수업의 검색·추가 조건을 바꾸지 않는다. 간편·고급 작성 왕복 시 키보드 초점도 복구한다.

도감은 검색·기구칩·큰 그림·보기/추가 중심으로 바꿨다. 검토 기록, 비교, 패턴 도해, 영상·수집 자료와 복잡한 필터는 `자료와 고급 도구`에서 사용할 수 있다. 기본 화면과 도구 화면은 동시에 마운트하지 않는다. 검색 상태는 기존 복구 훅으로 이어진다.

저장함에서는 불러오기와 수업 시작을 주 행동으로 분리하고, 일정에서는 다음 수업 준비와 날짜 탐색을 먼저 보여준다. 기존 자료 내보내기·복제·삭제 보호·일정 CRUD·휴무/장소 관리·초안 복구는 유지한다.

## 모션과 그림에 적용한 변경

### 그림의 공통 기준

목록, 수업안, 저장한 수업, 일정, 진행 화면의 동작 그림은 `MovementPhaseDiagramSvg`에서 파생되는 공통 모델을 사용한다. 같은 모델의 시작·정점·종료를 98종 × 3장, **294개 SVG 캐시**로 생성한다. 생성물과 manifest의 해시를 빌드 전에 검사한다. 단순 업스케일이나 파일 해상도 증가를 품질 개선으로 계산하지 않았다.

손과 발의 실루엣은 해당 쪽 손목·발목을 기준으로 만든다. 반대쪽 발을 다른 쪽 발의 절대 좌표로 재사용하던 문제를 수정하고, 양쪽 뒤꿈치·손을 모델에 포함했다. 좌우 보기와 화면 반전도 관절부터 말단까지 함께 적용한다. 리포머/캐딜락 다리 스트랩은 발목에 연결하고, 체어 페달은 실제 회전 끝점과 발의 접점을 공유한다.

밴드와 길이방향 폼롤러를 실제 도구 형태로 표시한다. 접촉 위치를 아직 작성하지 않은 볼·링은 인체에 붙여 정확한 사용법처럼 보이게 하지 않고 별도 `도구 참고`로 표시한다. 그림의 작은 라벨이 전문 검수를 대신하지 않는다.

### 중간 자세와 연결

프리뷰는 모든 동작을 동일한 8초 및 94% 종료 지점에 억지로 맞추지 않는다. 동작별 `keyframes`, `authoredEndProgress`, `endPoseLabelKo`, `finishBehavior`를 사용한다. 작성된 세 번째 자세에 도달한 뒤 시작으로 돌아가는 구간을 별도로 확보하며, 교대 동작은 가운데 자세나 반대쪽 니폴드 연결을 드러낸다. UI에 연결 자세로 이동하는 버튼을 추가했다.

프레임 경계에서 빠지던 반대쪽 관절과 보간 중 무릎·팔꿈치 굽힘 방향이 뒤집히는 문제를 수정했다. 관절 연속성 검사는 자연스러운 의학·생체역학적 움직임의 전문 승인을 의미하지 않는다. 모든 프리뷰 시간은 수업 타이머와 독립적이다.

과거 98종의 출처·검토 원장은 그대로 보존했다. 현재 도해의 대상이 달라진 12개 기록은 대상 불일치로 드러내며, 과거 기록을 고쳐 새 도해의 검수가 끝난 것처럼 처리하지 않는다. 추가 60종도 이 과거 검토 범위에 포함하지 않는다.

## 영상 연결 정책

기존 98종의 직접 영상 공백 중 12개에 기존 풀의 관련 자료를 연결했다. 5개는 이름 대응 참고, 7개는 관련 변형 참고다. 메타데이터 확인, 이름 대응 검토, 재생 확인, 특정 구간 확인, 정확 동작 검증은 별개 필드다. 새 연결 모두 실제 재생·구간·정확 동작·전문가 검증 상태는 `false`다. `startSec: 0`은 검증된 시작 지점이 아니다.

Single Leg Kick에 연결된 Open Leg Rocker 영상은 제거하고 제작자 설명 원문을 별도 sidecar에 보존했다. Going Up Side의 오연결과 전체 수업 링크 4개를 기존 개별 후보로 교체했다. 일반 추천, 수집 추천, 미디어 matcher가 같은 의미 필터를 사용하므로 같은 기구·부위·수업 구간만으로 다른 동작 영상을 강제 추천하지 않는다. 적합한 후보가 없으면 빈 목록을 유지한다.

기본 카탈로그는 기존 98종과 이전 작업에 있던 추가 60종을 합한 158종이다. 추가 60종과 별도 수집 60종에는 전용 자세를 작성한 것으로 꾸미지 않고 영상 참고/기구 안내를 표시한다. 사용자 저장 데이터의 직접 수정한 영상 링크를 덮어쓰는 마이그레이션은 추가하지 않았다.

## 검증 및 알려진 한계

- 새 store/UI 회귀는 실제 Zustand 상태로 추가·재정렬·잠금·시간·저장·복구·시작과 저장 실패, 오래 열린 편집창의 덮어쓰기를 검사한다.
- 모션 회귀는 98종의 관절 유무, 모든 경계의 연속성, 촘촘한 사이클 샘플, 좌우 반전 및 접촉을 검사한다. 생성 캐시는 별도 해시 검사로 연결한다.
- 테스트 이름에 남은 역사적인 `3D`, `98/141`, `48-render` 문구가 새로운 고유 동작 수나 검증 완료 수를 의미하지 않는다.
- 이 환경의 별도 Chromium은 소켓 권한으로 실행하지 못했고, 권한 확대는 정책상 거절됐다. 공유 브라우저도 로컬 서버 연결 거부 및 오류 페이지 URL 정책 제한으로 실제 데스크톱/모바일 시각 검증을 완료하지 못했다. 이를 통과로 보고하지 않는다. 브라우저 검증은 허용된 개발 환경에서 `pnpm dev` 후 수행해야 한다.
- 기존 24개 래스터 패밀리 전부를 새로 제작하지 않았다. 98개 항목이 모두 고유한 3D 동작을 갖게 된 것도 아니다. 특히 와이드 풋워크의 정면 폭, 링 접촉, 복합 시리즈의 모든 변형, 완전한 다축 원운동과 실제 영상 프레임 매핑은 남아 있다. 전문 인체·기구 검토는 미완료다.
- 작성 중 수업의 자동 보관과 진행 타이머의 새로고침 복구는 다른 기능이다. 기존 진행 타이머는 새로고침 시 같은 시점에서 재개한다고 약속하지 않는다.
