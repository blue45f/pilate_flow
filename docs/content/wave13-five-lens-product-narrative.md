# Pilates Flow Atelier — 5-Lens 제품·콘텐츠 내러티브 초안 (Wave 13)

> 저장소 실측 데이터(158종 동작 카탈로그, 730개 로컬 WebP 자산, 활성 CSS 16종 한글 타이포그래피 규율, `backend/freeAiService.ts` 타임아웃·로컬 폴백, `useManagedRaf` 언마운트 정리, 한글 IME `isComposing` 가드)를 기반으로 작성된 5가지 채널용 초안입니다. 외부 실측 지표가 필요한 항목은 `[측정 예정]` 자리표시자로 구분했습니다.

## 1. Contrarian Take — AI가 꺼져도 50분 수업을 안 끊는 오프라인 엔진
**제목:** 필라테스 강사 앱에 필요한 건 "더 똑똑한 AI"가 아니라, AI가 꺼져도 50분 수업을 안 끊는 오프라인 엔진이다.

스튜디오 수업 5분 전, 지하층이나 혼잡한 시간대에 Wi-Fi가 흔들리는 순간 클라우드·AI 의존형 앱은 가장 먼저 멈춥니다. Pilates Flow Atelier는 `backend/freeAiService.ts`의 프로바이더별 `AbortController` 타임아웃 보호와 로컬 규칙 기반 폴백, 그리고 브라우저 내 멱등 자동 저장을 기본값으로 둡니다. 강사에게 진짜 필요한 신뢰는 "화려한 추천 문구"가 아니라 "네트워크가 끊겨도 오늘 50분 수업 시퀀스가 그대로 열리고 타이머가 돌아가는 기본기"입니다.

## 2. Personal Story Hook — 한글 검색창 Esc 한 번과 실수 복구의 UX
**제목:** 한글 검색창에서 Esc 한 번 눌렀다가 158개 동작 필터가 통째로 닫힌 날.

- **Setup:** 수업 5분 전, 리포머 시퀀스 마지막 동작을 급히 바꾸려고 한글로 동작명을 검색하던 상황.
- **Friction:** macOS 한글 IME 조합 중 키 이벤트가 필터 드로어의 `Escape` 핸들러와 충돌해 검색 흐름이 통째로 끊기는 마찰.
- **Lesson:** `ExerciseAtlasView`, `FlowAtlasCatalog`, `PilatesVideoLibrary`에 `isImeComposing(event)` 가드를 적용하고, `usePilatesStore` 양방향 `Undo/Redo`와 `FiveMinutePrepDrawer` 원탭 복구 버튼을 연결했습니다. 현장에서 체감 품질을 가르는 건 신기능 개수가 아니라 실수했을 때 1초 만에 돌아오는 안전망입니다.

## 3. Data / Evidence Angle — 시각적 소음 제거와 준비 속도의 상관관계
**제목:** 158종 동작·730개 WebP 도해·0건의 보라색 AI 슬롭 — "덜어낸 UI"는 강사의 준비 시간을 얼마나 줄일까?

- **검증된 제품 지표:** 158종 동작 카탈로그, 730개 로컬 WebP 모션 자산, 활성 CSS 16종 전체 `font-weight <= 600` · `italic 0건` · `purple 0건`, 시간·횟수·스프링 수치 `tabular-nums`, 한글 `word-break: keep-all`.
- **현장 베타 측정 계획:**

## 4. Practical Playbook — 수업 5분 전 한 손 4단계 루틴
**제목:** 수업 5분 전, 한 손으로 50분 리포머 시퀀스를 완성하는 4단계 체크리스트.

1. **조건 2탭 고정:** 50분·리포머 기본값에서 오늘 사용할 기구만 선택합니다.
2. **핵심 동작 담기 & 잠금:** 꼭 넣어야 할 핵심 동작 2~3개를 담고 잠금으로 시간을 고정합니다.
3. **시간 맞추기 자동 보정:** 잠근 동작과 중간 휴식을 보존한 채 50분 정각으로 맞춥니다.
4. **라이브 수업 뷰 전환:** 큰 `tabular-nums` 타이머와 핵심 호흡·스프링 큐만 보며 진행하고, 실수 시 되돌리기/다시 실행으로 즉시 복구합니다.

*(앱 내 `SequenceWorkbench`의 `수업 5분 전 한 손 점검` 드로어에 실시간 인터랙티브 체크리스트로 탑재됨)*

## 5. What They Missed — 정직한 출처·도해 구분 UX
**제목:** "완벽한 동작 도해"보다 강사에게 더 중요한 건 "검증 전 동작을 솔직하게 표시하는 UX"다.

전용 도해가 없는 동작에 비슷한 자세 이미지를 억지로 돌려 쓰거나, 미검수 참고 자료를 의학적 처방처럼 포장하면 현장 강사가 가장 큰 리스크를 떠안게 됩니다. Pilates Flow Atelier는 전용 도해와 참고 영상 동작을 구분해 표시하고, 내 강사 검토 기록 완료/미완료 수와 비의료·수업 보조용 고지를 투명하게 노출합니다.
