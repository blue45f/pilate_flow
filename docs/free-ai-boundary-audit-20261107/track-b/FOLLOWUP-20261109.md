## 실제 재현과 위험

수정 전 기존 DEFECT-B1/B2/B3 테스트는 3/3 통과했다. 이는 안전을 증명한 것이 아니라 **결함이 존재하는 동작을 기대하는 테스트**였다.

- B1: 선택하지 않은 검토 블록의 강사 메모와 합성 secret이 `postAssist` 요청에 포함됨을 재현했다. 이는 브라우저→애플리케이션 서버 경계 노출이다. 해당 예시를 서버 스키마가 거절했으므로 실제 외부 AI까지 전송되었다고 단정하지 않는다. 검토 카탈로그·블록 전체에 대한 클라이언트 가드도 없었다.
- B2: 중첩 배열 속 apiKey 필드가 보존되고, 김민지 회원/박서연님, 출산 8주차, 복직근 이개, 허리·무릎 통증이 탐지되지 않았다. 공유 서버 스키마의 탐지 공백이므로 단순 UI 문제가 아니다. 추가 회귀를 수정 전 실행하여 16개 중 12개 실패로 확인했다.
- B3: 502 발생 중 연결됨 표시 모순은 기준 main에서 이미 해결되어 있었다. 이전 탭 성공 피드백 잔류와 `invalid_paid_model_blocked` 시 로컬 폴백 누락은 남아 있었다. 탭 이동·왕복 후 늦게 도착하는 응답/오류의 화면 오염도 추가 재현했다.

## 수정

- 시퀀스 요청은 선택된 동작·블록만 포함한다. 블록의 자유 강사 메모는 선택 여부와 무관하게 외부 요청에서 제외한다.
- 수업 초안 카탈로그는 요청 기구·난이도 범위로 축소한다.
- 전송 직전 완성된 요청 전체의 secret·민감정보를 검사한다. 캐시 키에도 실제 최소화한 후보 내용을 포함해 같은 ID의 내용 변경이 이전 결과를 재사용하지 않게 한다.
- secret 필드 제거는 중첩 배열까지 순회한다. schema와 로컬 엔진이 가벼운 공통 탐지기를 공유하며 한국어 이름 문맥·산후 주수·일반 통증을 함께 탐지한다.
- 유료 모델 차단은 로컬 엔진으로 전환하며 반복 외부 요청을 하지 않는다.
- 탭 이동 시 피드백을 지우고, 이전 탭 요청의 늦은 응답·오류는 현재 화면에 적용하지 않는다.
- 감사 테스트를 결함 재현 기대에서 안전 동작 기대와 실제 transport 호출 횟수 검증으로 변경했다. 감사 요약도 고정된 `reproducedInTest: true` 대신 회귀 검증 결과로 표시한다.

## 검증 범위와 한계

테스트는 합성 입력, 실제 client 함수, React DOM 이벤트, 캡처된 transport payload를 사용한다. 실제 개인정보나 실제 외부 AI 호출은 사용하지 않았다. 운영 배포·운영 네트워크 검증은 하지 않았다. 정규식 탐지는 모든 이름·건강정보를 완벽하게 판별하는 보장이 아니며, 일반 수업 문구 보존과 알려진 위험 사례의 차단을 검증했다. 운영 노출 사고 발생 여부를 확인한 감사 로그는 없다.
