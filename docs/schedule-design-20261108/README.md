# 강사 일정 화면 개선 검증 · 2026-11-08

## 구현 범위

- 선택한 주의 날짜 스트립: 요일, 날짜, 실제 예정 회차 수, 선택 날짜와 오늘 표시.
- 날짜 버튼의 단일 Tab 진입점, 좌우 화살표/Home/End 이동, 주·연도 경계와 1900–2199 제한.
- 좁은 화면은 44px 터치 영역을 유지하며 날짜 스트립 내부만 가로 스크롤. 현재 선택 날짜를 보이는 범위로 이동.
- 수업 카드에 실제 시작·종료 시각으로 계산한 소요 분 표시, 시간·제목·장소·동작 버튼의 시각적 계층 정리.
- 일간 빈 상태에서 해당 날짜의 수업 추가. 주간 빈 날짜는 간결한 표시와 기존 날짜별 추가 버튼 유지.
- 날짜 탐색과 일정 목록을 먼저 배치하고 시퀀스 준비 도구는 목록 아래로 이동. 저장 위치와 외부 캘린더 비연결 안내 유지.

일정 저장·취소·이동·반복 수정 모델, 기존 시퀀스 계획 모달과 다른 페이지는 변경하지 않았다. 반복 일정의 우측 범위 선택 패널은 이번 구현에 포함하지 않는다.

## 검증

- 일정 관련 Vitest: 8파일, 45테스트 통과. 새 6테스트 포함.
- Chrome의 격리된 합성 데이터: 320/390/768/1440px에서 일간·주간 문서 가로 넘침 0, 브라우저 오류 0.
- 키보드 날짜 이동, 오늘 복귀, 일간/주간 반복 전환, 수업 추가 모달 반복 열기/Escape 닫기·초점 복귀, 월간 준비 모달 닫기 확인.
- 위 탐색·모달 동작 후 일정/저장 수업/기록/현재 초안/날짜별 계획 데이터가 시작 상태와 동일함을 확인.
- 변경 파일 ESLint와 git diff --check 통과.
- 별도 Vite 프로덕션 출력 빌드 통과. verifyPwaBuild의 프로젝트 내부 출력 검증 API로 46개 정적 파일 검증 통과. 기존 dist와 다른 작업의 서버는 수정하지 않음.
- 전체 테스트 및 공유 checkout의 최종 타입 검사는 다른 변경과 함께 별도 집계한다. 초기 타입 검사 통과 뒤 동시 변경 파일의 타입 오류가 일시 관찰되었으므로 초기 결과를 최신 전체 통과로 확대하지 않는다.

## 증거와 한계

- before/final-320/390/768/1440.png: 실제 렌더 전후 화면. week-*.png: 개선 후 주간 화면.
- before.json/final.json과 verify.cjs: 브라우저 검증 결과와 재실행 스크립트. PLAYWRIGHT_PATH 및 SCHEDULE_QA_URL 환경변수로 설치 위치와 서버를 지정 가능.
- 모든 화면 데이터는 검증용 합성 데이터이며 실제 회원·수업 기록이 아니다.
- v5 일정 시안의 내용 설명은 참고했으나 구현 executor에서 원본 이미지 직접 픽셀 대조는 미수행. 원본과 동일함/전체 디자인 완료를 뜻하지 않는다.
- 실제 iOS Safari, 실물 기기, 운영 배포 버전은 검증하지 않았다. 이번 작업은 배포·원격 push하지 않았다.
