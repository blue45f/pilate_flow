# 수업 기록 목록 개선 범위

진행 중인 화면 대조·개선 작업입니다.

- 사용자 재첨부 schedule-saved-history-concept(1).png의 오른쪽 모바일 기록 화면을 기준으로 390/768/1440px 실제 화면을 대조한다.
- ‘당시 시퀀스 보기’가 먼저 보이고, ‘복사해 새 수업 만들기’는 별도 보조 동작으로 구분한다.
- 기록 당시 스냅샷 조회와 현재 초안을 바꾸는 복사 핸들러를 혼합하지 않는다. 조회는 원본·초안·저장 데이터를 바꾸지 않아야 한다.
- 장소처럼 기록 모델에 없는 값을 현재 일정에서 가져오거나 시안의 예시 값을 만들지 않는다.
- 기존 검색/필터/기록 상세/복사/삭제·복구·안전 안내는 유지한다.
- 모바일·태블릿·PC에서 실제 순서, 색상 대비, 줄바꿈, 키보드·초점, 조회와 복사 결과를 검증한다.
