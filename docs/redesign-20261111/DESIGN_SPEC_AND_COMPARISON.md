# Pilates Flow — 페이지별 동선 분리 단계형(Step-by-Step) 재설계 명세서

## 1. 핵심 문제 진단 및 재설계 원칙

### 실제로 확인한 문제 (Observed UX Issues)
1. **단일 화면 정보 과밀**: 첫 진입 시 상단 여정 바, 수업 조건 칩, 기구 리본, 시작 옵션 4종, 추천 갤러리, 최근 수업, 자동 구성, 도해 둘러보기, AI 도우미까지 한 화면에 동시에 노출되어 처음 들어온 강사가 **"지금 무엇부터 눌러야 하는지"** 바로 파악하기 어렵습니다.
2. **동선 혼재로 인한 입력 부담**: 수업 조건 설정, 동작 검색·담기, 순서·시간 편집, 고급 기구 분석이 한 페이지 스크롤 안에 섞여 있어 화면마다 시선이 분산됩니다.
3. **단순 시간 조절의 번거로움**: 개별 동작 시간을 30초(`0.5분`) 늘리거나 줄이려 해도 블록 편집 시트(인스펙터)를 열어야 했습니다.
4. **보관함 재사용 및 수업 진행 시선 분산**: 저장한 시퀀스의 `복제`와 `수업 시작`이 `더보기` 안쪽에 숨겨져 있고, 수업 진행 화면(`LiveStageView`)에서 모바일·태블릿 세로 화면 기준 **다음 동작과 스프링 준비 정보**를 한눈에 보기 어렵습니다.

### 추정 문제 구분 (Inferred Pain Points)
- 수업 직전 5~10분 사이에 스마트폰으로 급히 순서를 손보는 강사는 복잡한 분석 패널보다 **큰 단계 버튼과 빠른 시간 가감(`-30초` / `+30초`), 직전 실수 되돌리기**를 훨씬 자주 사용할 것으로 추정됩니다.

### 핵심 설계 원칙: **"1 페이지 = 1 질문 = 1 명확한 다음 행동"**
사용자의 피드백(*"한 화면이 너무 복잡한 것보다 동선을 최대한 분리해서 한 페이지에 많은 정보를 입력하지 않고 페이지별로 바로 이해되게"*)을 반영해 전체 흐름을 **단계형(Option B 개선안)** 으로 재정립했습니다.

| 단계 | 화면 질문 (1초 이해) | 화면에 보이는 핵심 요소 (최소 입력) | 다음 행동 버튼 |
| :--- | :--- | :--- | :--- |
| **시작 · 1단계** | **어떤 수업을 만들까요?** | 시간(`30/50/60분`) · 기구(`리포머/매트/체어/캐딜락/바렐`) · 난이도(`기초/초중급/중상급`) 원탭 칩 + `최근 수업 이어하기` | **다음: 동작 담기 →** |
| **2단계** | **어떤 동작을 넣을까요?** | 검색창 + 기구/부위 필터 + 고화질 도해 동작 카드 + `+ 추가` 버튼 (선택형 `AI 동작 추천`) | **다음: 순서·시간 다듬기 (N개) →** |
| **3단계** | **순서와 시간만 맞춰 볼까요?** | 담긴 동작 카드 목록 + 드래그/화살표 이동 + 카드 내 **`-0.5분 / +0.5분` 원탭 시간 조절** + `목표 시간 자동 맞춤` | **다음: 최종 확인·저장 →** |
| **4단계** | **저장하고 수업을 시작할까요?** | 전체 시간·구간 비중 요약 + `저장` / `사본 저장` + `시퀀스 미리보기` → `수업 시작` | **수업 시작 →** |
| **수업 진행** | **지금 동작과 다음 세팅은?** | 현재 동작 큰 제목 + 고화질 도해 + 초대형 타이머 + 핵심 큐 2줄 + **타이머 바로 아래 `다음 동작·스프링 미리보기`** | `이전` · `일시정지/재생` · `다음` (`되돌리기`) |

## 3. 시안 비교 및 최종 선택 근거

1. **시안 A (단일 화면 좌우 분할 캔버스)**: 데스크톱 숙련자에게는 빠르지만, 첫 사용자와 모바일 화면에서는 검색과 편집이 한 화면에 겹쳐 복잡도가 높음.
2. **시안 B (페이지별 동선 분리 단계형 — 최종 선택)**:
   - **첫 사용 이해도 최상**: 각 단계에서 해야 할 행동이 단 1가지로 명확해 설명서 없이 첫 수업을 완성할 수 있음.
   - **인지 부하 및 입력 최소화**: 기본값 칩만 탭하고 넘어가면 되며, 고급 도구(3D 점검·흐름 분석·AI 보조)는 선택형 접기로 분리해 화면이 깔끔함.
   - **접근성 및 기존 호환성 100% 유지**: 최소 `44×44px` 터치 영역, 키보드 포커스 링, `prefers-reduced-motion`, 기존 v3 로컬 스토리지 및 98개 동작 카탈로그와 완벽 호환.
3. **시안 C (가로 타임라인 리본형)**: 전체 비중 파악에는 좋으나 모바일에서 가로 스크롤 조작이 번거로움.
