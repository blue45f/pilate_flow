# 참고 영상과 동작 연결 점검

2026년 11월 27일 앱의 기본 동작 524개와 변형 1,228개를 실제 갤러리 함수로 조회했다. 동작 영상 풀의 561편과 수업 자료·기구 참고에서 추가로 발견한 35편을 합쳐 YouTube 주소 596개를 대조했다.

| 공개 페이지에서 읽은 항목 | 영상 수 |
| --- | ---: |
| 식별 가능한 제목 | 596 |
| 게시 채널 표기 | 544 |
| 제작자 설명 | 516 |
| 설명 앞부분에서 찾아낸 챕터·구간 시각 | 154 |
| 자막 텍스트 | 499 |
| 제목을 읽었고 설명과 자막은 추출되지 않은 페이지 | 65 |

각 수치는 겹친다. Firecrawl이 반환한 공개 페이지에서 제목, 설명, 자막 구역을 구분했다. 각 주소에서 해당 구역이 제공되는지 기록했다. 동작 연결을 고칠 때는 게시자 설명의 앞 2,500자와 자막 앞 13,000자 이내의 발췌문 또는 시각이 있는 자막을 읽었다. 짧은 음악 자막도 텍스트가 있으면 자막 제공 수에 포함된다. 다른 형식으로 반환된 페이지에서는 이 집계에 쓰는 채널·설명·자막 구역이 빠질 수 있다. 페이지 제공 여부와 영상 전체의 재생 가능 여부는 별도로 확인해야 한다. ## 어떤 동작에서 볼 수 있는지

| 종류 | 전체 동작 | 갤러리에서 참고 영상이 열리는 동작 | 연결 근거가 없어 갤러리가 빈 동작 |
| --- | ---: | ---: | ---: |
| 기본 | 524 | 259 | 265 |
| 변형 | 1,228 | 630 | 598 |
| 합계 | 1,752 | 889 | 863 |

기본 동작 259개 중 217개는 동작명, 가까운 변형 또는 수업 구성 동작과 연결된다. 나머지 42개에는 이전에 등록한 참고 링크가 있다. 영상이 있는 변형 630개에서는 기본 동작에서 가져온 참고 자료라는 표시가 붙는다. 변형에 따라 도구, 속도, 손발을 짚는 위치가 달라진다. 그중 40개에는 별도의 동작명·변형·구성 동작 기준에 맞는 영상도 있다. 갤러리에 실제 나타나는 고유 영상은 349편이다. [1,752개 동작별 연결 목록](./2026-11-27-movement-video-coverage.csv)

## 실제 자료로 고친 연결

- 매트 골반 시계의 예전 주영상에서는 강사가 리포머에 누워 시범한다고 말한다. 매트 참고 자료를 바꾸고 제작자가 적은 앞뒤 0분 41초, 좌우 2분 27초, 원 그리기 4분 3초, 반대 방향 5분 21초를 표시했다. [이전 리포머 시범](https://www.youtube.com/watch?v=0dhzD6d1ru0) · [Complete Pilates 골반 시계](https://www.youtube.com/watch?v=3GBwBBt63Xw)
- 한국어 매트 호흡 수업은 앉아서 시작한다. 강사는 4분 2초 무렵 누운 자세에서 다시 숨을 쉬며 갈비뼈 움직임을 느끼는 방법을 안내한다. 그 부분을 누운 호흡 동작에서 열 수 있다. [누운 호흡 설명](https://www.youtube.com/watch?v=M2Y9FWJYO0k&t=242s)
- 점프보드 수업의 자동 자막을 대조한 결과 강사는 서서 하는 런지에서 네발기기로 넘어간다. 누워서 하는 와이드 프로그 점프는 기구 이름만으로 이 영상에 연결되지 않는다. [점프보드 수업](https://www.youtube.com/watch?v=9v6mYwGxnuE&t=68s)
- 체어 프로그는 체어를 바라보고 하는 동작과 등을 돌려 하는 동작에 서로 다른 영상을 연결한다. 래더 바렐과 스파인 코렉터도 세부 기구와 동작명을 함께 확인한다. [체어를 바라보는 프로그](https://www.youtube.com/watch?v=Y0XdJQkqBrU) · [체어를 등지는 프로그](https://www.youtube.com/watch?v=O2jKA5-9WoU) · [제작자의 Facing Out 자세 설명](https://onlinepilatesclasses.com/pilates-exercises/wunda-chair-exercises/wunda-chair-frog-facing-out/)
- 매트 하이 시저스에 연결된 영상의 강사는 다른 동작인 밸런스 컨트롤을 소개한다. 하이 시저스는 같은 이름의 매트 자료로 바꾸고 이전 영상은 밸런스 컨트롤로 정정했다. [하이 시저스](https://www.youtube.com/watch?v=Rrf4ORXQINU) · [밸런스 컨트롤](https://www.youtube.com/watch?v=0O_Tay-g3NY)
- 기구별 참고 자료에 적혀 있던 매트 수업의 게시 채널을 Idit Spiro Pilates와 Quiet Bodies로 정정했다. 체어·캐딜락 수업 3편의 게시자도 Pilates by Brittany로 바로잡았다. 기구별 수업 영상 설명에서는 일률적인 스프링 색상과 반복 속도 처방을 덜어냈다. [Idit Spiro Pilates의 매트 수업](https://www.youtube.com/watch?v=qkdhm5r8NoQ)

## 11월 27일 플레이어 화면 확인

공식 임베드 플레이어 13편 중 3편에서 자세가 보이는 정지 화면을 확인했다. 아래 시각은 플레이어에 이동을 요청한 위치다. 캡처에는 영상 시계가 표시되지 않았고 연속 재생 시간은 계측하지 못했다. 나머지 10편은 재생 화면에서 로그인을 요구했다. 각 영상의 결과는 영상별 CSV 마지막 열에 기록했다.

| 영상 | 열기를 요청한 위치 | 화면에서 확인한 내용 |
| --- | --- | --- |
| [체어 프로그 Facing In](https://www.youtube.com/watch?v=Y0XdJQkqBrU&t=77s) | 1분 17초 | 강사가 체어 오른쪽에 서서 아래쪽 스프링을 설명하는 장면이었다. 이 캡처에서는 손과 발을 지지하는 시점을 볼 수 없었다. |
| [리포머 풀링 스트랩 1](https://www.youtube.com/watch?v=JWjHmpg6aXI&t=13s) | 13초 | 롱박스에 엎드린 시범자는 가슴을 살짝 들고 양손을 엉덩이 옆에 두고 있었다. 다리는 뒤로 길게 뻗어 있었다. |
| [래더 바렐 숏박스 시리즈](https://www.youtube.com/watch?v=waGj9pn2e-U&t=174s) | 2분 54초 | 바렐 위에 앉아 무릎을 굽혔다. 두 발은 사다리 쪽에 있고 상체를 세운 채 양손을 몸 앞에 뒀다. |

체어를 등지는 프로그의 양손·양발 위치는 제작자의 글에서 확인했다. 좌판 앞쪽에 양손을 짚고 페달에 두 발을 올리도록 설명한다. [Facing Out 자세 설명](https://onlinepilatesclasses.com/pilates-exercises/wunda-chair-exercises/wunda-chair-frog-facing-out/)

앱에서 시각 링크를 제공하는 12편은 근거에 따라 표시한다. 7편은 이전에 실제 재생 화면으로 확인한 특정 장면, 2편은 제작자의 챕터, 3편은 시간 정보가 있는 자동 자막을 사용한다. 자막에 없는 관절각이나 반복 속도는 이 기록에서 계산하지 않았다. [이전 재생 관찰의 시각과 자세](./2026-11-19-video-playback.md)
