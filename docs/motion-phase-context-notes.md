# Phase context notes

`getMotionPatternPhaseContext(reference, progress)` resolves the selected authored phase using the explicit family/variant identity and the existing definition's intervals, label and declared display behavior. Finite progress is clamped to `0..1`; phase intervals are half-open, with `1` assigned to finish. Unknown identities and non-finite progress return `null`.

All 22 existing references retain their current phase label, cycle support summary and source context. Fourteen older definitions still have no declared display behavior; their value remains `unknown`. Twenty-one references have `detailStatus: available` with phase-by-phase (`setup → move → turn → return → finish`) posture and contact change notes in `src/data/motionPhaseContextNotes.ts`, and one reference (`quadruped-leg-slide`) remains `detailStatus: not_authored` to preserve explicit UI coverage for unwritten phase annotations alongside `unknown` display behavior. This does not change any existing authored asset status.

The twenty-one annotation sets in `src/data/motionPhaseContextNotes.ts` describe inspected local geometry across `src/models/motionAuthoringBatch.ts`, `src/models/pelvicCurl.ts`, `src/models/supineReach.ts`, `src/models/chestLift.ts`, `src/models/seatedBandRow.ts`, `src/models/heelRaise.ts`, `src/models/clam.ts`, `src/models/supineDrafts.ts`, `src/models/lateralDrafts.ts`, `src/models/quadrupedDrafts.ts`, `src/models/reformerFootwork.ts`, `src/models/chairPedalPress.ts`, `src/models/reformerStrapArmPress.ts`, `src/models/cadillacArmSpringPress.ts`, and `src/models/standingSupportDrafts.ts`:

- `chair-seated-overhead-sidebend-v1` & `chair-seated-bilateral-arm-raise-v1`: seated 6-link torso and 2-link arms on an ordinary chair; seat and foot contacts stay fixed, and neither hand becomes a chair support contact. Evidence: `src/models/motionAuthoringBatch.ts`, `seatedPose`.
- `prone-forearm-chest-extension-v1` & `prone-single-straight-leg-extension-v1`: prone forearm chest lift (head/chest already above the mat at setup and finish; pelvis, forearm/hand and forefoot constraints persist) and prone single straight-leg lift (active forefoot contact changes from `fixed` to `released` during move/turn/return). Evidence: `src/models/motionAuthoringBatch.ts`, `pronePose`.
- `articulated-pelvic-curl`, `supine-chest-lift`, `floor-seated-band-row`, `supine-single-leg-reach-v1`: segmented spine/pelvis mat patch transitions (`spine-2-mat` released at rest in `pelvicCurl.ts`), bilateral `scapula-mat` release (`chestLift.ts`), seated band endpoints with unmodeled force (`seatedBandRow.ts`), and raised head/chest tabletop single-leg reach (`supineReach.ts`).
- `supported-heel-raise`, `side-lying-clam`, `adult-supine-heel-slide`, `supine-knee-fold`, `side-lying-straight-leg-lift`, `side-lying-open-book`, `quadruped-arm-slide`: ordinary chair-rail heel raise (`heelRaise.ts`), fixed hip-heel axis clam rotation (`clam.ts`), supine sliding vs. lifted foot constraints (`supineDrafts.ts`), side-lying straight-leg lift and open-book with authoring-choice head pad (`lateralDrafts.ts`), and quadruped palm-patch forward slide (`quadrupedDrafts.ts`).
- `reformer-parallel-footwork`, `chair-seated-pedal-press`, `reformer-supine-strap-arm-press`, `cadillac-supine-arm-spring-press`, `ladder-supported-hip-extension-slide`, `ladder-supported-side-leg-slide`: apparatus schematics with explicit unmodeled spring forces and fixed/sliding support constraints (`reformerFootwork.ts`, `chairPedalPress.ts`, `reformerStrapArmPress.ts`, `cadillacArmSpringPress.ts`, `standingSupportDrafts.ts`).

Each set persists the inspected `motionStudyLedger.json` source fingerprint. If that entry's fingerprint changes, `detailStatus` becomes `stale` and the resolver omits all old pose/contact annotations and qualifications. Current phase and cycle context remain available. Inspect the changed model before replacing an expected fingerprint. The browser comparison relies on the generated ledger's freshness; the existing ledger generator/check remains responsible for matching that ledger to source bytes.

These notes provide phase-level changes across an interval, not measured contact states at every instant. The basis is `authored-model`; no annotation grants source-video matching, exact source-variant matching, clinical suitability, pressure validation, professional review, or recommendation eligibility. They do not describe getting into/out of posture, class warmup/cooldown, or a prescribed hold. The existing source/review worksheet remains the place for source records and review export.
