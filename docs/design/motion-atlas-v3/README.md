# Motion atlas v3

Generated with OpenAI imagegen on 2026-11-14 for Pilates Flow. These are original editorial assets, not creator video frames.

The practitioner source is a transparent 3 × 3 sheet with a right-facing chestnut-bun head, closed sage-olive sleeveless torso, hip, upper arm, forearm, hand, thigh, calf and ivory sock foot. It is attached to the authored joint geometry; no generated anatomy is used to infer movement mechanics.

The equipment source is a 3 × 2 sheet with pale oak and olive Reformer, Cadillac, Wunda chair, ladder barrel, mat and props. It supplies reference illustrations. Motion support surfaces remain the authored geometry so contact locations remain consistent.

Original PNG files are retained in source/. Shared runtime WebP files use quality 88 and alpha quality 100. The practitioner is 768 × 768 and equipment 1536 × 1024. Sprite coordinates are normalized to the original practitioner size, 1254 × 1254.

These replace artwork reconstructed after unpushed workspace state was lost. Validation and file sizes must be measured against this release, not the lost preceding build.
