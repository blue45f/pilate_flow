## 범위와 실제 확인

기준은 로컬에 이미 확인된 origin/main `5161c22ece19d069b5da10ed4126080bd0d29836`이다. 이번 작업은 최신 원격 상태를 다시 읽거나 원격 main에 통합하지 않았다.

Mac Downloads의 `class-insights-three-devices-concept.png`를 실제 이미지로 열었다. SHA-256은 `099a568e1be239dc258c8cb090ba9891c286ce6b4d45e5398b95f79e8e794412`이다. 원본에는 데스크톱·태블릿·모바일 구성 탭, 계획 요약, 시간 막대, 접힌 표, 부위 태그가 있다. 이 구조는 이미 구현되어 있어 새로 구현했다고 주장하지 않는다.

남은 시각 차이는 선택 탭이었다. 실행 화면은 회색 배경 위 흰색 선택 카드이고 시안은 흰색 배경 위 민트색 선택 영역이다. 전용 `class-insights.css`의 탭 배경과 선택 색만 조정했다. 선택 여부는 기존 ARIA 속성과 글자·경계로 유지한다. 시안의 예시 50분/8개/2개를 데이터로 복사하지 않았으며 앱의 실제 계획 계산과 안내를 보존한다.

개인정보 코드, 공통 스타일, 수업 진행, 스토어, 엔진, 데이터, 운동 검토 상태는 수정하지 않았다. Gemini 및 운영 배포도 실행하지 않았다.

## 브라우저 증거

`before-*`는 기준 실제 실행, `after-*`는 변경 후 실제 실행 이미지다. 시안 자체가 아니다. 격리된 Chrome 프로필에서 기존 카탈로그의 서서 발목 움직임 하나를 임시 수업에 추가했다. 사용자 프로필이나 저장 데이터를 사용하지 않았다.

`results.json` 및 `verify.cjs`는 320×760, 390×844, 768×1024, 1440×900, 390×500, 320×760의 글꼴 200% 검사를 보존한다. 각 조건에서 탭의 선택 색, ArrowRight/End/Home, 표 열기·닫기, Escape·닫기 버튼·배경 클릭, 초점 복귀, 재진입 초기 탭, localStorage 불변을 확인했다. 가로 넘침과 페이지 오류는 모두 0이다. 모바일 및 데스크톱 최종 스크린샷을 직접 열어 시안과 대조했다.

초기 제한 실행의 Chrome 프로세스가 SIGABRT로 종료되어 정식 권한 심사 후 격리 브라우저 검증을 실행했다. 수정 후 개발 서버의 이전 CSS 응답으로 선택색 회귀가 한 번 실패했으며, 서버를 재시작하고 새 로컬 포트에서 최종 CSS를 다시 검증했다. 설치가 필요한 pnpm 실행은 레지스트리 정책으로 차단되어 설치하지 않았고 이미 설치된 도구만 사용했다.

실물 기기, Safari, 운영 배포, 사용자 실제 데이터 검증은 포함하지 않는다. 전체 9종 시안의 모든 상태가 완성되었다고 주장하지 않는다.
