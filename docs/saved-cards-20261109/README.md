# 저장한 시퀀스 카드 · 2026-11-09

## 직접 대조한 시안

사용자 재첨부 `schedule-saved-history-concept(1).png`의 가운데 모바일 저장 화면을 직접 픽셀로 확인했다. SHA-256은 `e505cc9b949e298bcaba481d659f4d8593fad09aa419fd12b919aeeaea5c1468`이다. 해당 시안의 검색 → 간결한 제목/설명 → 열기/더보기 흐름을 현재 저장 카드에 반영한다. 시안의 예시 수치나 운동 검증 상태를 실제 데이터로 옮기지 않았다.

## 반영

- 카드의 기본 화면은 제목, 설명, 불러오기와 더보기다. 기존 불러오기 이름·동작은 유지한다.
- 더보기는 카드 안에서 펼쳐지며 시간 구성, 동작·휴식 미리보기, 수정 날짜, 수업 시작, 복제, 인쇄, 텍스트 내보내기, 기록하기, 삭제를 모두 보존한다.
- 예시 계획 표식과 복구 자료 안내는 접히지 않는다. 페이지의 자료 안전 안내와 저장 상태 안내도 유지한다.
- 기본 펼침 상태는 기기 크기와 무관하게 닫힘이며 UI에만 존재한다. 저장 데이터·회복 모델·운동 콘텐츠를 변경하지 않는다.
- 펼침 상태는 배열 순서가 아닌 시퀀스 ID로 관리한다. 복제 후 정렬이나 검색으로 다른 카드가 잘못 열리지 않는다.
- 접기나 다른 카드의 더보기 조작은 미확정 삭제를 취소한다. Escape는 해당 더보기 버튼으로 초점을 돌려준다.
- 인쇄창을 열어도 카드 도구는 계속 펼쳐 두므로 닫기·Escape·배경 클릭 뒤 원래 인쇄 버튼으로 복귀한다.
- 삭제 취소는 삭제 버튼으로, 확정 삭제는 다음 카드의 불러오기 또는 검색창으로 초점을 옮긴다. 기록 보존 정책은 기존대로다.
- 복구 가능한 임의 문자열 ID를 UTF-16 고정 길이 hex로 바꾸고 패널/버튼 접두사를 분리했다. `a`/`a-toggle` 충돌과 단독 surrogate의 URIError를 회귀 테스트로 막는다.

## 검증

- 관련 7파일, 64테스트 통과. 새 8테스트는 접힘/전체 도구 보존, 표식/복구 안내 노출, 특수 ID/ARIA/초점, 인쇄 초점, 삭제 확인 취소·보존·후속 초점, 복제/정렬/검색, 기록/수업 진입을 포함한다.
- TypeScript, 변경 파일 ESLint, diff 공백 검사 통과. production build/PWA는 정적 파일 47개 및 manifest·PNG 아이콘 통과. 기존 큰 bundle 경고는 남아 있다.
- 실제 Chrome 7조건: 320×760, 390×844, 768×1024, 1024×768, 1440×900, 1024×500, 320×760의 root 글꼴 200%.
- 모든 조건에서 가로 넘침 0, 페이지 오류 0. 숨겨진 도구의 Tab 제외, Enter 펼침, Escape 접힘, 인쇄창 세 가지 닫기와 초점, 텍스트 파일 내용, 삭제 취소·대상 변경, 기록창 취소, 복제/정렬/삭제, 검색, 새로고침 데이터 보존을 확인했다.
- 합성 카드의 기본 높이는 일반 조건에서 약 148–149px, 큰 글꼴 조건에서 약 219px였다. 제목·복구 안내가 길면 높이를 강제로 자르지 않는다.
- 별도 기록 폼 검증에서도 이 더보기를 실제 눌러 기록 진입→저장/재로드/이력 재열기→수업 시작→타이머→기록 흐름을 320/390/768/1440px에서 통과했다.
- 읽기 전용 코드 검토에서 발견한 ID 충돌/인코딩 문제는 위 회귀 테스트와 함께 수정했다.

## 경계와 남은 검증

합성 데이터를 사용하는 격리된 Chrome 검증이다. 실물 모바일/Safari, 운영 배포 버전의 확인은 포함하지 않는다. 수업 기록 페이지 레이아웃, LogSessionModal, 운동 콘텐츠 및 다른 디자인 방향은 변경하지 않았다. 전체 회귀 및 원격 통합 결과는 최신 main을 병합한 뒤 아래에 기록한다. 운영 배포를 실행하지 않는다.
