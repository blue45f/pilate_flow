# 자세·부위 시각 안내

## 구현 범위

동작 선택 상세(`LibraryMovementInspector`), 전체 정보(`YouTubeClipModal`), 수업 블록 상세(`StepBlockInspector`)의 읽기 전용 패널을 공통 `PostureAnatomyGuide`로 연결했다. 기구 선택/필터, 수업 기록, 원본 메타데이터, 개인 검토 상태와 수업안은 변경하지 않는다.

- 바로 누움, 엎드림, 옆으로 누움, 앉음, 무릎 섬, 섬, 네발기기의 7개 자체 제작 SVG 방향 그림.
- 앞면·뒷면을 명시한 신체 지도와 같은 번호의 부위/원래 태그 범례. 색만으로 매핑하지 않는다.
- 대둔근과 햄스트링의 일반 역할을 범례에서 확인하고, 세부 설명과 자료는 키보드로 열 수 있다.
- 척추 굴곡·신전·측굴·회전·중립 계획 태그의 정적 방향 기호. 실제 척추 분절 움직임이나 관절 각도 시범이 아니다.
- 원래 카탈로그의 일반 부위 태그 모두를 지역 또는 비해부학 목표로 분류. 호흡·균형은 특정 근육에 연결하지 않는다. 사용자 자유 입력은 정확히 등록된 문자열만 매핑하고, 미연결 태그를 숨기거나 임의 추정하지 않는다.
- 둔근/대둔근/중둔근·소둔근을 구분한다. 목 앞·뒤, 위팔 앞·뒤, 어깨 뒤, 골반 바깥 앞, 허리 뒤는 다른 지도로 표시한다. `척추분절근`은 기존 묶음 표현으로 남기며 정식 단일 근육명으로 확정하지 않는다.
- 심부 구조를 겉면에 투영한 넓은 위치 그림이다. 정밀 근육 경계, 기시·정지, 좌우 수행, 실제 활성도, 개인별 적합성이나 효과를 검증하지 않는다. 기존 주의 메모와 전문 검토 경계를 유지한다.

## 근거 대조 (2026-11-09 KST)

외부 도판은 복제·트레이싱하지 않았다. 그림은 코드로 새로 작성했고 아래 교재의 위치·기능 설명만 참고했다. 자료를 대조했다는 사실은 전문 해부학 검수나 운동 효과의 근거가 아니다.

1. [OpenStax A&P 2e §1.6](https://openstax.org/books/anatomy-and-physiology-2e/pages/1-6-anatomical-terminology): 바로 누움은 얼굴 위, 엎드림은 얼굴 아래. 신체 앞뒤 및 지역의 용어 확인.
2. [OpenStax A&P 2e §11.6](https://openstax.org/books/anatomy-and-physiology-2e/pages/11-6-appendicular-muscles-of-the-pelvic-girdle-and-lower-limbs): 대둔근의 고관절 폄, 뒤 허벅지 햄스트링의 무릎 굽힘과 대부분의 고관절 폄 기능, 앞/뒤/안쪽 허벅지 근육군 위치 확인. 모든 햄스트링이 동일하게 고관절을 지난다고 표현하지 않는다.
3. [OpenStax A&P 2e §11.3](https://openstax.org/books/anatomy-and-physiology-2e/pages/11-3-axial-muscles-of-the-head-neck-and-back): 척추기립근군과 다열근을 구분하고 척추 주변의 깊이와 역할 대조.
4. [OpenStax A&P 2e §9.5](https://openstax.org/books/anatomy-and-physiology-2e/pages/9-5-types-of-body-movements): 척추 굴곡/신전/측굴/회전의 개념 방향 대조. 중립은 기존 계획 태그를 표현하며 정확한 개인별 정렬을 정의하지 않는다.
