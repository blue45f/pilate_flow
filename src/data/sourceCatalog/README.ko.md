## 포함 내용

- verified-source-catalog.json: 공식기관 본문을 확인한 운동 참조 18개와 시리즈 참조 3개, 원천 16개. 기관·문헌 확인과 전문 강사 검수를 구분합니다.
- korean-candidate-catalog.json: WITH PILATES 국내 영상 후보 9개. 제작기관 대표의 교육기관 공식 자격을 확인했지만, 개별 영상 재생·한국어 음성·실제 시연자·촬영 품질은 미확인입니다.
- review-queue.csv: 30개 항목을 한 번에 검수할 수 있는 표입니다. 시리즈 3개는 개별 동작으로 계산하거나 자동 편성하면 안 됩니다.

## 현재 검증 범위

공개 웹사이트 영상 2개에서 운동 3개를 부분 재생·프레임·자막 확인했습니다. 체어 풋워크(0:23), 미니볼 사이드 린(0:48.821), 미니볼 힙 신전(1:37.429)의 시점은 **실제로 관찰한 시점**이며 정확한 동작 시작점이 아닙니다. 영상 전체 검수 0개, 전문 강사 승인 0개, YouTube 임베드 허용 확인 0개입니다. 전체 재생을 보거나 음성 품질을 청취 완료했다고 주장하지 않습니다.

래더바렐 영상 재생 요청 뒤 관찰 도구의 읽기 호출이 시간 초과되었습니다. 프레임·타임스탬프 검수가 완료되지 않아 문헌 확인 상태로 유지했습니다.

## 분류 원칙

리포머·체어·래더바렐·캐딜락·매트를 구분했습니다. 소도구는 링, 저항밴드, 루프밴드, 미니볼, 짐볼, 폼롤러 등을 구분합니다. 기구와 부위는 공식 본문 근거를 남기고, 확인하지 못한 난이도·타임스탬프·동작 시간은 null로 둡니다. 국내 후보의 이름 기반 부위 태그는 미검토입니다.

출처 자격은 교육·자격 발급기관의 공식 소개에서 확인한 범위만 기재했습니다. 이는 독립적인 임상·촬영 품질심사가 아니고, 대표나 기관의 자격이 개별 영상 시연자의 자격을 자동 보증하지도 않습니다.

## 앱 적용

1. 자료 탐색·원본 보기·검수 대기 목록으로 먼저 사용합니다.
2. 모든 auto_recommendation_eligible 값은 false입니다. 강사가 실제 영상·기구·수준·주의·회원 적합성을 확인한 뒤에만 승인합니다.
3. 보조자가 필요한 Back Splits, 역위성 Roll Over, 고급 기구 운동은 기본 자동추천에서 제외합니다.
4. 출처의 스프링 수·색을 다른 기구 브랜드나 회원에게 그대로 일반화하지 않습니다.
5. 골반 전방/후방 경사는 관찰 태그로, 추천 목표는 골반 움직임 인지·조절/몸통–고관절 협응/가동성/근력·지구력/균형처럼 표현합니다. 체형만으로 통증 원인·근육 단축·약화를 진단하거나 교정·치료 효과를 보장하지 않습니다.
6. 직접 만든 모션은 이 목록과 섞지 말고 generated_motion=true, professional_review_status=미검수로 분리합니다. 이 카탈로그는 모두 generated_motion=false이며 원본 참고 링크입니다.
